# Contributing to dtmi4-socket

Thank you for your interest in improving dtmi4-socket. The project is developed
and maintained by **Digital Application Solutions SL** ([dastions.com](https://dastions.com)),
and community contributions are welcome.

## How to contribute

1. Open an issue describing the bug or the improvement before starting large
   changes.
2. Fork the repository and create a branch from `main`.
3. Keep changes focused, follow the existing code style and add or update the
   Jest tests (`npm test` must pass).
4. Open a pull request explaining what changes and why.

Never include real `.env` values, device tokens, certificates or customer data
in issues, commits or pull requests. Report security vulnerabilities privately
to support@dastions.com instead of opening a public issue.
